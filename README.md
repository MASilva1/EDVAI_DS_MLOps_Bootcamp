# Data Science & MLOps | Prácticas de Escuela de Datos Vivos

**Python · SQL · Análisis exploratorio · Clasificación · Regresión**

Repositorio de materiales y notebooks de práctica de formación en Data Science y MLOps (Escuela de Datos Vivos AI). Se presenta como **trayectoria de aprendizaje**, separada de mis proyectos de automatización administrativa aplicados.

## Tecnologías y áreas de práctica

- Python y notebooks reproducibles.
- Consulta, unión y preparación de datos.
- Exploración de datasets y análisis de variables.
- Prácticas de clasificación y regresión con datos de ejemplo.
- Organización de archivos de datos y modelos asociados.

## Cómo revisar el trabajo

Entrá a cada carpeta y abrí el notebook correspondiente. Los notebooks son ejercicios de formación: **no representan un modelo desplegado en producción**, una solución MLOps productiva ni resultados validados fuera del marco del curso. La procedencia de datasets y materiales pertenece a las actividades educativas; se deben respetar sus licencias y condiciones.
